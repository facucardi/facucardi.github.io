# Facundo Cardinal · Portfolio

Live site: **https://facucardi.github.io/** · English version: **https://facucardi.github.io/?lang=en**

Case studies of the products I've designed and built: AI integrations (MCP, custom GPTs, multi-provider assistants), customer-facing web portals, an MRP engine in C# / .NET 8, and data tooling for a CRM/ERP.

Single-file static site (HTML/CSS/JS), bilingual (ES/EN), data-driven: every page and every downloadable project card is generated from one `PROJECTS` array in `index.html`.

## Update

- **Add a project:** copy one `{ ... }` block in `PROJECTS`, give it a new `id`, edit the `es` / `en` texts and push.
- **Résumé button:** keep `CV_Facundo_Cardinal_ES.pdf` and `CV_Facundo_Cardinal_EN.pdf` in the repository root; the button shows up automatically.
